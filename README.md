# 棋类对战平台（面向对象技术及应用大作业·第一阶段）

支持 **五子棋** 与 **围棋** 双人对战的控制台棋类平台。后端（对局逻辑）与客户端（指令交互）分离，客户端以同样的形式对待不同棋种。

## 构建与运行

```bash
make            # 生成可执行文件 boardgame
./boardgame     # 启动平台
make clean      # 清理构建产物
```

要求：C++11 及以上编译器（g++ / clang++ 均可）。

## 功能一览

- 开局选择棋种（1-五子棋 / 2-围棋）与棋盘大小（8~19），黑方先行、双方交替落子
- 五子棋：任一方向连成五子判胜，棋盘下满判平局
- 围棋：提子（无气即提）、自杀禁着、打劫/全局同形禁着、虚着（pass）、双方连续虚着后按中国规则数子法（黑贴 3.75 子）判定胜负
- 悔棋一步（每方每局限 3 次）、投子认负（认负方输，立即终局）
- 局面保存到文件 / 从文件读取覆盖当前局面
- 操作提示可隐藏与重新显示；所有指令均有反馈；非法输入给出错误提示

## 指令集

| 指令 | 说明 |
| ---- | ---- |
| `start [类型 尺寸]` | 开始游戏（不带参数则交互式询问；类型 1-五子棋 2-围棋，尺寸 8~19） |
| `move 行 列` | 在指定位置落子（1 起始坐标，如 `move 5 5`） |
| `pass` | 虚着（仅围棋） |
| `undo` | 悔棋一步（每方每局限 3 次） |
| `resign` | 当前行棋方投子认负 |
| `restart` | 对局进行中重新开始（同棋种同尺寸） |
| `save 文件名` | 保存当前局面 |
| `load 文件名` | 读取存档覆盖当前局面 |
| `hint on/off` | 显示 / 隐藏操作提示（不带参数则切换） |
| `quit` / `exit` | 退出程序 |

## 架构与设计模式

```
src/
├── Stone.h            棋子枚举（棋子不建对象，落子只改格子值）
├── Board.h/.cpp       棋盘（网格缓冲复用）
├── Game.h/.cpp        对局抽象基类：place()/pass() 模板方法 + 规则钩子
├── GomokuGame.*       五子棋规则（连五判胜 / 满盘平局）
├── GoGame.*           围棋规则（提子 / 禁着 / 数子法，搜索缓冲复用）
├── GameMemento.*      备忘录：局面快照 + 存档序列化
├── GameFactory.*      简单工厂：按棋种与尺寸创建对局
├── GameController.*   后端外观 + 备忘录管理者（悔棋栈 / 存读档 / 认负）
├── UIBuilder.h/.cpp   建造者：界面组件（横幅/棋盘/状态/消息/帮助）装配 + 指挥者
├── ConsoleClient.*    命令行客户端：指令解析 / 转发 / 反馈
└── main.cpp           入口（无全局变量）
```

- **模板方法**：`Game::place()` 固定"校验→落子→规则效果→记录→判终→换手"流程，五子棋/围棋只实现规则钩子
- **简单工厂**：`GameFactory` 按编号创建对局，尺寸校验集中在工厂
- **备忘录 + 管理者**：每手棋前拍摄 `GameMemento` 快照入栈，悔棋与存读档共用同一套快照与序列化
- **建造者**：界面由五种组件装配，指挥者固定装配顺序；第二阶段实现 GUI 时新增建造者即可
- 后端与客户端仅通过 `GameController`/`Game` 抽象交互，降低耦合；不使用全局变量
